# SpiderKeeper

Дневник владельца пауков-птицеедов. Приложение работает на GitHub Pages по адресу [redkoivan7-wq.github.io/SpiderKeeper/](https://redkoivan7-wq.github.io/SpiderKeeper/).

## Проверка ветки до публикации

Распакуйте архив ветки или переключитесь на неё в локальной копии репозитория. Из корня проекта запустите сервер с Node.js 22 или новее.

```sh
node tests/serve.mjs
```

Откройте [127.0.0.1:8000/SpiderKeeper/](http://127.0.0.1:8000/SpiderKeeper/). Локальный адрес имеет отдельное хранилище. Чтобы проверить реальные записи, скачайте копию со старого сайта и импортируйте её на локальной странице в разделе «Настройки». Для автоматического прогона в отдельном профиле Chromium выполните команду ниже. При необходимости укажите путь к Edge или Chrome в переменной SPIDERKEEPER_BROWSER.

```sh
node tests/browser.mjs
```

Для ручной проверки добавьте паука с фото, измените его имя, запишите кормление и линьку. Выберите день в календаре и отметьте напоминание выполненным. Перезапустите страницу и убедитесь, что записи сохранились. Проверьте копию в отдельном профиле браузера и попробуйте поймать насекомое, поставить игру на паузу и возобновить её.

## Установка и перенос данных

На iPhone откройте адрес в Safari, выберите «Поделиться» и «На экран „Домой“». Если есть переключатель «Открыть как веб-приложение», включите его. Проверьте запуск с иконки и нижнюю навигацию в портретной и альбомной ориентации. На Android или Windows воспользуйтесь установкой приложения из меню совместимого браузера.

Дождитесь надписи «Готово к работе без сети» и проверьте повторный запуск в авиарежиме. Для первого открытия на телефоне нужен HTTPS. Тестовый HTTP-сервер предназначен для браузера на том же компьютере.

Резервные копии переносят карточки, журнал, напоминания, фото, настройки анимации и игровой рекорд. На iPhone у веб-приложения с экрана «Домой» отдельное локальное хранилище. Скачайте резервную копию в браузере, где вели дневник, и импортируйте её в установленном приложении.

Источники по установке и хранилищу. [Apple](https://support.apple.com/en-az/guide/iphone/iphea86e5236/26/ios/26) · [WebKit](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)

## Данные и обновления

- При первом открытии в прежнем хранилище приложение читает ключ `spiderkeeper_v1` и переносит карточки и события в IndexedDB. Исходный ключ сохраняется. Время в старых событиях остаётся пустым, поскольку в прежней версии его не записывали.
- Импорт принимает исходный JSON-дневник и текущий формат. При конфликте идентификаторов с разным содержимым сохраняются обе версии и их связи. Повторный импорт той же копии пропускает совпадающие записи.
- Фотографии хранятся как файлы в IndexedDB. Отображение HEIC зависит от поддержки браузера. Для просмотра одного фото на разных платформах подойдут JPG и PNG.
- Напоминания отображаются на главной странице и в календаре. Даты и время задаёт владелец.
- При изменении файлов оболочки увеличьте версию `CACHE` и обновите список `shell` в `sw.js`. Новая версия начинает работу после подтверждения из интерфейса или после закрытия окон старой версии.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | Оболочка приложения и адаптивные стили |
| `app.js`, `ui.js` | Навигация, формы, карточки, календарь и настройки |
| `storage.js` | Миграция, IndexedDB, фотографии и резервные копии |
| `catalog.js` | Справочник видов со ссылками на World Spider Catalog |
| `game.js` | Отрисовка террариума, мини-игра и управление |
| `pwa.js`, `sw.js`, `manifest.webmanifest`, `icons/` | Установка, автономный запуск и обновления |
| `tests/` | Локальный сервер и проверка пользовательских сценариев в Chromium |
